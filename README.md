This repository provides a Julia interface to the floating-point numberic types available in FLINT <https://github.com/flintlib/flint> using the latest Julia binary wrapper FLINT_jll.jl <https://github.com/JuliaBinaryWrappers/FLINT_jll.jl?.  

The interfacing is informed by Nemo.jl <https://github.com/nemocas/Nemo.jl> and Arblib.jl <https://github.com/kalmarek/Arblib.jl>.
